# AGI黎明

面向公开访问的技术文章阅读站，提供管理员私人归档能力；当前仍仅在本机运行。

文章保留原文收录，可自动为外文标题、摘要和新收录的外文正文生成中文译文；列表优先显示中文标题，普通文章页有译文时默认中文，元信息行可打开来源原文。翻译由 worker 处理，模型开关开启且预算可用时才调用；标题和摘要覆盖已有公开文章，无需全文许可，正文仍需来源允许站内全文且不自动批量补译已有文章。私人历史归档保留原文。不调用写作或评分模型。可按来源、分类、主题、上海日期和关键词查找；缺发布时间时明确显示收录时间。已确认[6类与初始14个技术主题](docs/reader/category-topic-proposal.md)；新文章先“待分类”，站主可以在后台新增、改名和分配分类，并管理主题名称与说明。

首页列表居中且最大宽度1082px，桌面使用独立内容面，标题按发布时间倒序排列并展示最多两行摘要；摘要优先中文译文，缺译文时使用原摘要，无摘要时省略。公开展示清理匹配文章的RSS尾注、旧译文新增标签及已核实的来源占位摘要，不按长度隐藏有效短摘要。日期按上海时区显示，缺少发布时间时显示收录时间；保留阅读和点赞统计。桌面侧栏全站保留可折叠类别，默认展开，Cookie记忆展开状态并用于首屏渲染；折叠后只留一条分隔线，并显示当前非默认类别名称。详情高亮文章类别，探索和我的只高亮当前模块。首页保留语义标题，顶部以检索工具栏和主题导航取代大标题行；桌面收紧文章间距，搜索、来源与日期工具栏随滚动吸顶，主题与结果计数随列表滚动；按站点优先项和已有主题顺序展示最多5个快捷主题，随宽度折叠，相邻的“更多主题”入口按同一顺序展示当前隐藏的主题和公开篇数。手机使用独立的类别与主题入口，底栏保留文章、探索、我的。

普通文章页在宽屏使用正文与目录相邻的两栏，没有目录时正文居中；窄桌面与手机使用正文前的目录入口。桌面右侧目录默认展开，可整栏收起为紧凑的展开按钮；折叠前后正文左边缘固定，正文向右填满目录让出的空间；切换保持章节内阅读位置和子章节的手动折叠状态，刷新或切换文章后重新展开。目录默认展开嵌套章节，手动收起优先；当前章节被收起时由父项提示位置。标题下集中展示来源、作者、日期、统计、近似阅读时长与原文链接；列表与详情的来源、日期、阅读量和时长使用统一线性图标，阅读量以眼睛图标配数字展示；“打开原文”使用浅底描边按钮。有正文译文时标注“中文译文”，主题单独一行；只保留元信息下的一条横线，导语以灰色竖线区分。右下角依次提供阅读设置、专注模式、主题切换和固定占位的返回顶部，后者随滚动渐显、隐藏时保留空位。专注模式开关与列表进入详情使用短淡化，保持正文位置；详情标题和返回后的原文章链接承接键盘焦点。系统开启“减少动态效果”时仍保留现有动画与平滑滚动。目录展开时默认正文宽度为760px，可按阅读偏好调窄或调宽；收起目录后在当前宽度基础上向右扩展，“宽”模式再额外增加最多100px，窗口空间不足时按可用宽度收敛。详见[文章阅读工具调整](docs/reader/article-controls.md)。

搜索位于检索工具栏左侧，来源与日期在右侧，窄屏自动换行。搜索框右侧使用单个放大镜按钮，停顿300ms后更新，中文组词期间暂停，回车或点击图标立即提交；清空同步解除关键词条件。来源选择立即生效；连续操作筛选时保留最新在途条件，请求完成不覆盖期间新输入的搜索文字，包括浏览器后退／前进期间的新输入；导航开始前尚未提交的搜索草稿仍取消；日期支持近7/30/90天并显示预设选中状态；日历跟随当前编辑的起始或结束字段，支持单端和同日范围、悬停预览及天数说明。输入首次离开字段后就近报错，接受斜线日期并规范为 YYYY-MM-DD；可直接选择年月、将结束日期设为北京时间今天。近7/30/90天与“不限日期”作为快捷操作，点击立即应用并关闭浮层；自定义日期先修改草稿，确认后应用，取消或Esc放弃。范围包含起止当天；手机起止字段并排，浮层内容可滚动，底部范围说明与操作保持可见。组合筛选显示可逐项移除的已选条件，日期合为一项；单一条件不重复展示。类别和主题的“全部”入口只移除各自条件，并保留其他筛选；“清除全部筛选”重置所有条件并保留每页篇数。列表显示匹配总数；日期筛选无结果时，可一键解除日期限制或重新选择日期，并在存在匹配文章时提供最近有文章的北京时间日期入口，两种日期跳转均保留其他筛选和每页篇数。无结果且设置了来源或关键词时，正文内提供“移除来源限制”“清除关键词”，每次只移除对应条件，保留其他筛选和每页篇数。零结果隐藏底部分页。有结果时支持数字分页、任意跳页及每页25/50/100篇，默认25篇；每页数量写入URL，刷新和返回保留。底部分页左侧显示当前篇数范围与总数，右侧依次为页码、按需显示的跳页和每页条数选择器，按可用宽度同排或换行；桌面页码为32px紧凑控件，当前页使用浅蓝底色，每页篇数标签位于白底胶囊选择器外侧，菜单只显示数字，并在支持原生菜单样式的浏览器中显示圆角浮层、浅蓝选中项与右侧勾号；前后页使用带悬浮提示的箭头图标。页码全部可见时隐藏跳页，出现省略号时支持回车或点击“跳转”，失焦不跳页。分页链接沿用站内按下时预取的导航方式。键盘焦点位于分页链接时，可用 ←／h 和 →／l 切换前后页；其他区域的按键不触发翻页。更改筛选或每页数量都从第一页开始，超出末页的页码回到最后一页。详情页不设返回按钮，使用浏览器后退／前进恢复历史中的筛选、分页和滚动位置；旧 `/all` 地址保留查询条件跳转到首页。

“探索”集中展示主题与来源卡片，可在页内切换。卡片保留文章数与最近更新时间，主题另显示最新文章和近30天篇数。点击卡片或文章中的主题／来源，统一进入“文章”的对应筛选；重新筛选回到第一页，清除恢复未筛选列表。旧目录及详情地址自动重定向。手机底栏为文章、探索、我的。

公开页面不存在或文章已下架时，404 页面保留站点侧栏，展示斜切圆形数字与查找说明；搜索框通过回车或搜索按钮进入首页的关键词结果，不继承失效链接中的旧筛选。页面另提供“浏览全部文章”“探索主题”两个按钮，悬停或键盘聚焦时从相反方向滑入换色；系统开启“减少动态效果”时仍保留过渡。启用 JavaScript 后，页面可见且连续 8 秒无操作会自动返回首页，并替换 404 历史记录；鼠标、键盘、输入、焦点与滚动操作重新计时，切回页面重新给满 8 秒。页面显示倒计时，可取消本次自动跳转；提交搜索或在当前窗口选择恢复按钮后停止计时，侧栏导航加载期间暂停，等待响应时不覆盖手动导航。邮件联系入口使用 `site/site.ts` 的 `SITE.contactEmail`。加载失败另提供“重新加载”，错误响应保持真实状态码与 `no-store`。

当前本机配置下，普通文章页直接显示已采集的正文与本地保存的图片；未取得正文时显示缺失提示和原文链接。收藏、阅读状态、私人笔记、历史版本和离线ZIP仍需登录管理员，私人资料不进入普通文章响应或正文ZIP。信源模板的 `site_fulltext` 仍默认关闭，当前本机数据库的五个信源已按站主授权开启；服务仅监听本机，未公开上线。

站内统计在文章详情进入前台时计一次，同一浏览器对同一篇文章30分钟内去重；它不表示读完或独立人数。匿名点赞按同一浏览器同篇文章一票，可取消；页首和文末共享请求状态，提交期间同步禁用，结束后同步恢复。零阅读与点赞数字不展示，点赞入口保留；访问过的文章标题以浏览器历史颜色区分，不等同私人“已读”。公开页面不显示尚未开放的收藏占位；管理员私人收藏仍仅管理员可见。统计历史从启用后累计，清除 Cookie 或更换浏览器后无法把访问认作同一人。

公开搜索包含原文与当前有效中文标题、摘要、来源、当前主题名及获准展示的原文和译文正文；中文按连续文字、英文按词边界匹配，多个词可分布在不同字段或语言中。正文中的加粗、强调等行内标签不拆开文字；摘要和来源名称按公开展示规则清理后参与匹配，已移除的尾注不计入结果和总数。结果高亮标题/摘要，并在需要时显示正文或原文命中片段。进入详情保留关键词，在当前可见内容中高亮并提供首处匹配定位；原文命中而当前显示译文时明确提示并提供原文入口。定位由点击触发，保留浏览器历史滚动恢复；仅公开材料参与，私人笔记与历史快照不进入公开搜索。已有文章无需重采集或重翻译即可应用这些规则，撤销全文许可或修改原文后相应旧译文立即失效。

桌面内容与右侧浮动工具各有空间，正文宽度调整和专注模式保持布局占位。列表文章主区域及留白可点击，同时保留选字和独立来源/点赞操作；有全文时显示近似阅读时长，明确截取正文开头的摘要在需要时补省略号。详情省略重复导语，文末提供原文、点赞、主题与最多三篇公开相关文章；Geoffrey Huntley 文章省略文末重复的来源、原文入口与点赞行，页首信息及后续阅读保留。图示完全未保存时保留就地可点击原文提示，完整表格不算缺图；此展示修复不自动恢复已丢失的图像。查看器提供适应窗口、原尺寸、按当前显示比例逐级放大/缩小、百分比与平移；缩放保持视野中心，深色正文图片轻度调暗。

## 本机运行

需要 Node.js **24.22.1+**、PostgreSQL **17**，以及同主版本的 `pg_dump`/`pg_restore`、`tar`。OpenAI 工程文章的浏览器指纹传输还需要 Python **3.10+** 与 `curl_cffi`；安装、部署与恢复步骤见 [Linux 部署](docs/deploy.md)。

```bash
npm ci
python3 -m venv .data/curl-cffi
.data/curl-cffi/bin/pip install --only-binary=:all: -r deploy/curl-cffi-requirements.txt
node scripts/init-env.ts
# 编辑 .env：DATABASE_URL 指向专用新库 reader_dev，填写本机 API_BASE_URL。
node --env-file=.env scripts/migrate.ts
node --env-file=.env scripts/retire-reader-state.ts --database reader_dev
node --env-file=.env scripts/seed.ts
npm run build -w @agidawn/web
```

分别运行 `npm run dev:api`、`npm run dev:worker`、`npm run dev:web`。网页默认位于 [localhost:3000](http://localhost:3000)，后台 `/admin`，密码在私有 `.env` 的 `ADMIN_PASSWORD`。

本机日常使用已提供 [systemd常驻运行与启停命令](docs/deploy.md#本机常驻运行)，当前生产网页地址为 [localhost:4040](http://localhost:4040)，开发网页仍使用3000端口。私人书库支持标题、摘要、当前已保存正文和私人笔记关键词搜索，可与来源、类别、主题、收藏、阅读状态取交集；显示命中字段与片段，刷新和翻页保留条件。管理员文章页可阅读当前私人正文、收藏、写笔记，并勾选多个主题与分类一起保存。保存冲突保留选择，重新载入分类与主题不清除笔记草稿；历史版本保留独立入口，未保存笔记离开前会确认。

在私人书库筛选后可逐篇勾选或全选本页，批量设置分类、添加或移除主题。先检查所选标题和变更摘要，再确认保存；未指定的主题及其他标签保留。任一文章冲突则整批不保存。选择仅限本页，切换筛选、翻页或重载会清除，保存成功后按原筛选刷新。

同一选区可切换到“收藏与阅读状态”，批量收藏、取消收藏，或设为待读、在读、已读。两项可单独修改或一起设置，默认保留；预览确认后按私人状态版本整批保存，冲突保留选择和操作。私人笔记、分类、主题和正文保留；未选文章不变。无需变化的文章不增加状态版本或审计。

书库内“常用视图”可命名保存已应用的关键词和五种筛选条件，打开时从第一页查询最新匹配文章。支持改名、确认后用当前条件替换和删除；删除只移除视图记录，文章及私人资料保留。视图存入本机数据库，仅管理员可见；不保存未应用的输入或分页。列表加载失败不影响书库查询，冲突保留草稿，可单独载入已保存版本。

私人书库“笔记回顾”入口保留当前已应用条件，并切换为有笔记、按笔记最近更新排序。也可单独选择有笔记／无笔记及收录时间排序，与关键词和五种筛选组合；列表显示已保存笔记的纯文本片段和保存时间。空白笔记视为无笔记，新条件与排序可保存到常用视图，旧视图继续按原条件打开。

私人书库增加日期范围，可按收录时间或笔记更新时间填写开始／结束日期，允许只填一端；按北京时间包含两端整日。近7天、近30天包含今天，先填入日期，再点击“筛选”应用，其他输入保留。日期与搜索、现有筛选和排序取交集，沿用本页批量整理与导出；“清除日期”只清除日期输入。常用视图保存固定起止日期，不随每天移动；笔记日期只匹配有内容的已保存笔记。

勾选本页文章后可“导出所选笔记 Markdown（ZIP）”，每篇一个文件，保留当前文章信息、分类主题、收藏阅读状态和已保存笔记。无笔记的选中文章也有文件及明确提示。下载保留选择和整理草稿，不提交分类、主题或状态；选区变化、重载、导航或退出后会取消在途下载。详见[笔记回顾与批量导出验收](docs/reader/phase4-note-review-bulk-export-acceptance.md)。

登录后可在单篇“私人阅读”工具中“导出笔记 Markdown”，包含文章信息、分类主题、收藏与阅读状态及服务端已保存笔记，适合存入 Obsidian。导出不保存草稿、不修改文章或笔记，也不包含全文和图片；历史正文页导出的仍是该文章当前信息与已保存笔记。原有指定版本 ZIP 继续用于正文和资源归档。

私人当前正文与历史正文支持章节目录、当前章节提示和手机目录入口，阅读位置另存于服务端。重新打开后点击“继续阅读”，在标题、来源等信息变化但正文相同时仍可恢复；正文变化则保留旧位置并提供历史版本入口。阅读操作后自动合并保存位置，收藏和阅读状态仍由你手动设置。位置保存冲突或失败会暂停自动保存，可载入记录后继续；浏览器退出时的最后一次请求只能尽力保存，异常断电或离线可能丢失最后一小段进度。详见[笔记导出与继续阅读验收](docs/reader/phase4-note-export-reading-acceptance.md)。

普通文章右下角的省略号及私人当前／历史正文前的“阅读显示设置”使用三档单选组调整字号、行距和正文宽度；代码块与行号随字号同步调整，默认/较大/更大分别为13/14.5/16px；全部为默认值时禁用恢复默认。普通文章的图表质量提示仅在有外部引用未保存等具体问题时支持悬停、聚焦或点击文字查看详情；原站样式问题只保留提示条，不重复展开说明。× 菜单提供“本次关闭直到下次访问”和“永久禁用”。本次关闭在刷新或重新进入文章后恢复；永久禁用作用于当前浏览器所有普通文章，仅在已禁用时显示阅读设置中的恢复入口。隐藏仅针对图表，不影响其他正文质量说明。永久偏好在当前浏览器记忆并同步到同源标签页；存储不可用时仍在当前标签页生效并说明无法记住。排版变化按章节比例保持阅读点，不保存笔记草稿，也不修改收藏或阅读状态。显示偏好不进入数据库备份，换浏览器需要重新设置。详见[文章阅读工具调整](docs/reader/article-controls.md)。

第四阶段已完成新版配套备份的隔离恢复验收：私人笔记、收藏阅读状态、命名视图和阅读位置经过备份后恢复，搜索、图片、继续阅读和三种导出通过；原书库及备份保持，恢复副本与验收资料独立保留。详见[第四阶段整体验收与恢复演练](docs/reader/phase4-final-restore-acceptance.md)。

[主题管理](http://localhost:3000/admin/reader/topics)可查看名称、说明与关联篇数，新增、改名和编辑说明。改名保留已有文章归属，保存后各入口下一次读取即生效，无需重启API。初始词表由 `scripts/seed.ts` 或 `scripts/seed-topics.ts` 写入数据库，重复初始化不覆盖后台编辑。

采集、内部通知和 IndexNow 默认关闭。确认来源后设置 `COLLECT_ENABLED=true`；手动真实来源验收须显式执行 `node --env-file=.env scripts/validate-reader-sources.ts --live`，它会访问外网、收录列表并提取每源一篇样本，不调用付费正文兜底。

npm run typecheck
DATABASE_URL=postgres://127.0.0.1:5432/reader_test npm test
npm run build -w @agidawn/web
node --test apps/web/tests/*.test.ts
node scripts/smoke.ts --base http://localhost:3000

测试数据库名必须以 `_test` 或 `_ci` 结尾；测试账号需要建库权限。浏览器检查需要 Playwright Chromium/WebKit 及 Linux 运行库。自动测试只连接本地假源，与显式真实来源验收分开。
