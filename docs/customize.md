# 配置 AGI黎明

站名已经确定为 **AGI黎明**。`site/site.ts` 保存文案、联系信息和部署默认值；`site/brand/` 保存独立品牌图形。正式域名和 `site/pages/` 的使用规则、隐私说明由站主上线前确认。

## 分类与主题

文章初始归入虚拟分类“待分类”，不会凭模型猜测分类。管理员打开 `/admin/reader/categories` 新增或改名，在私人文章页选择分类并勾选主题，点击“保存分类与主题”。改名和分配带版本检查、审计；两个窗口同时修改时返回冲突，当前选择保留，可单独重新载入分类与主题，不影响笔记草稿。原内容管理中的人工覆盖入口继续可用。

本站已确认“智能体工程、AI 编程、产品与应用、评测与安全、系统与性能、观点与方法”六类，并保留“待分类”。词表边界见[分类与主题方案](reader/category-topic-proposal.md)，首批96篇的对应关系在 `industry/reader-taxonomy.json`。新收录文章仍先待分类，由管理员归档，不自动推断。

主题是可选的标签视图。初始14个技术主题由 `industry/topics.json` 初始化到数据库，日常在 `/admin/reader/topics` 管理；文件保留为首次初始化模板。一篇文章可有多个主题，列表一次选择一个主题，并与分类、来源、日期等组合筛选。主题根据稳定匹配关系生效，不根据说明文字或正文自动识别。

新增分类或主题均无需改代码。主题管理页展示名称、说明及关联文章数，并可进入对应书库；篇数与私人书库主题筛选一致，包含已下架文章及停用来源的已发布历史。新增填写唯一名称与说明，名称去首尾空白后1–60字符、不能换行，说明1–2000字符。保存后，筛选、单篇勾选、批量整理以及探索目录的下一次读取都使用最新目录，无需重启API；已打开的其他页面可刷新获取。

首页展示顺序在 `site/site.ts` 的 `ARTICLE_NAVIGATION`：`categoryOrder` 按类别名称排列，未列出的类别按数据库返回顺序追加；类别改名后仍可用，若需保持指定位置则同步改这里。`topicShortcuts` 使用稳定的主题 slug，当前为 Harness、MCP、Skills 三项；其余主题都可从“更多主题”打开。没有匹配的快捷主题时显示目录前三项。该配置只影响首页导航，不改变文章归属；更改后重新构建并重启 web。

主题改名、编辑说明只更新显示信息，原链接和文章归属保持稳定；新增主题使用独立身份，即使采用另一个已改名主题的旧名称，也不会自动关联旧文章。写入带版本检查及同事务审计；冲突保留输入，可点击“载入已保存版本”重新调整，其他表单草稿不清空。保存成功后列表刷新失败时，原地保留列表和其他草稿，可“重试刷新主题列表”，不会重复提交修改。

单篇主题勾选只替换目录所管理的主题标签，保留其他已有标签，包含隐藏的 `entity:` 标签；合计超过20个时拒绝保存。内部匹配标签由后端维护，不随主题名称改写。原内容管理的原始标签输入仍是完整替换列表，调整时须保留无关旧标签；维护脚本会显式合并。

私人书库可把来源、类别（含待分类）、一个主题、收藏和阅读状态按交集筛选；空选项表示全部。刷新、翻页保留条件，重新筛选回到第一页。私人历史继续包含停用来源和下架文章，与公开列表的可见范围分别处理。

批量整理先在私人书库筛选，再勾选文章或“全选本页”。默认每页40篇，最多100篇；选择不跨页，切换条件、翻页或重载会清除。批量分类默认“不改变分类”，选择“待分类”则明确清空分类；各主题可选择保留、添加或移除。未指定主题及隐藏实体标签保留。点击“检查批量变更”核对标题和操作，再确认提交；保存成功按原条件刷新，文章可能因此移出当前结果。

批次使用与单篇分类、人工可见性相同的版本检查，任一冲突、不存在、无效输入、标签超限或审计失败均整批回滚。冲突保留选择与操作，可返回调整；“重新载入列表并清除选择”获取新版本后重新勾选。没有实际变化的文章不新增人工覆盖，也不固定原本继承的标签。笔记、收藏、阅读状态、正文和归档均不参与批量修改。

私人书库的关键词还可搜索标题、摘要、当前已保存正文和私人笔记，显示命中字段与上下文。大小写不敏感，多个词均需命中，可分布在不同字段；最多200字符、6个词，`%`、`_` 等按普通文字处理。正文只检索与当前文章精确匹配的已保存快照，历史版本和未保存笔记草稿不参与。搜索不修改公开全文权限，也不向公开索引写入私人内容。

首批分类与标签通过[显式维护流程](deploy.md#首批分类与主题标注)应用，不在 seed 或采集过程中自动执行。仅标题摘要的21篇在清单中标为 `provisional:true`，审计原因注明待补正文复核；此标记是维护依据，不是新增的页面状态。

## 来源

五个初始来源在 `industry/sources.json`；`scripts/seed.ts` 只新增不存在的来源，不覆盖后台修改。暂停来源只停止后续采集，保留历史文章。人工下架是持久决定，重复采集和提取不会恢复公开。

`site_fulltext=false` 时普通文章页只展示摘要和原文链接；设为true后，可在普通文章页直接阅读已采集正文。站主已授权当前本机使用：数据库内五个既定信源均已开启，服务仍仅监听loopback。未取得正文的文章继续显示缺失提示；私人笔记、收藏和历史版本的管理员访问要求保持不变。信源模板仍默认关闭，外部部署的展示范围另行确定。

首次导入上限在 `config._agidawn.initialBackfillLimit`（默认30），月份在 `initialBackfillMonths`（默认12）。普通文章列表按完整匹配结果计数与数字分页，每页25/50/100篇，默认25篇，支持任意跳页，不设总共2,000条的访问上限；私人书库仍使用独立游标。付费提取器的预算在后台“设置”维护，所有付费请求保留回执。
