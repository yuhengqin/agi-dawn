# 配置 AGI黎明

站名已经确定为 **AGI黎明**。`site/site.ts` 保存文案、联系信息和部署默认值；`site/brand/` 保存独立品牌图形。正式域名和 `site/pages/` 的使用规则、隐私说明由站主上线前确认。

`SITE.contactEmail` 控制 404 页的邮件联系入口，设为 `null` 时隐藏该行；更改后重新构建并重启 web。

`ARTICLE_FOOTER.hideActionsForSources` 按稳定来源 ID 隐藏普通文章文末的来源、原文入口与点赞一行，当前为 `geoffrey-huntley`。页首信息、文末主题、继续阅读和私人阅读区保持；更改后重新构建并重启 web。

## 分类与主题

管理员从 `/admin/reader/taxonomy` 的“分类与主题管理”页维护两个目录。分类区块为 `#categories`，主题区块为 `#topics`。旧 `/admin/reader/categories` 和 `/admin/reader/topics` 链接分别转到对应区块。

文章初始归入虚拟分类“待分类”，不会凭模型猜测分类。管理员可在分类区块新增分类，或点击对应行的“改名”后编辑并保存。改名遇到版本冲突时，可在该行“核对已保存版本”，对照最新名称后再保存，新增栏与其他行的草稿会保留。在私人文章页选择分类并勾选主题后，点击“保存分类与主题”。改名和分配均检查版本。分类名称去除首尾空白后若相同，版本保持原值且不生成审计。实际改名的审计记录包含旧名称和新名称，分配也会记录审计。私人文章页发生冲突时保留当前选择，可单独重新载入分类与主题，不影响笔记草稿。原内容管理中的人工覆盖入口继续可用。

本站保留六类，当前后台名称为“Agent、AI Coding、产品与应用、Evaluating、系统与性能、观点与方法”，另有“待分类”。前三个英文名称分别沿用原“智能体工程、AI 编程、评测与安全”的分类身份，不改变文章归属或分类含义。词表边界见[分类与主题方案](reader/category-topic-proposal.md)，首批96篇的对应关系在 `industry/reader-taxonomy.json`。新收录文章仍先待分类，由管理员归档，不自动推断。

主题是可选的标签视图。初始14个技术主题由 `industry/topics.json` 初始化到数据库，日常在“分类与主题管理”页的主题区块管理；文件保留为首次初始化模板。一篇文章可有多个主题，列表一次选择一个主题，并与分类、来源、日期等组合筛选。主题根据稳定匹配关系生效，不根据说明文字或正文自动识别。

新增分类或主题均无需改代码。“分类与主题管理”页的主题区块默认展示已有主题的名称、说明及关联文章数，并可进入对应书库。篇数与私人书库主题筛选一致，包含已下架文章及停用来源的已发布历史。点击“新增主题”展开表单，填写唯一名称与说明。名称去首尾空白后1–60字符、不能换行，说明1–2000字符。保存后，筛选、单篇勾选、批量整理以及探索目录的下一次读取都使用最新目录，无需重启API。已打开的其他页面可刷新获取。

首页展示顺序在 `site/site.ts` 的 `ARTICLE_NAVIGATION`：`categoryOrder` 按类别名称排列，未列出的类别按数据库返回顺序追加，“待分类”始终放在最后；类别改名后仍可用，若需保持指定位置则同步改这里。`topicShortcuts` 使用稳定的主题 slug，当前为 Harness、MCP、Skills 三项；桌面最多展示五个快捷主题，“更多主题”按同一顺序列出当前未展示的主题和公开篇数。该配置只影响首页导航，不改变文章归属；更改后重新构建并重启 web。

主题改名、编辑说明只更新显示信息，原链接和文章归属保持稳定。新增主题使用独立身份，即使采用另一个已改名主题的旧名称，也不会自动关联旧文章。写入带版本检查及同事务审计。冲突时可点击“核对已保存版本”，查看最新名称和说明。已改过的字段保留草稿，未改的字段同步最新值。保存成功后若列表刷新失败，可“重试刷新主题列表”，其他草稿保留，也无需重复提交。在“分类与主题管理”页的两个区块之间切换时保留草稿；离开整个管理页时，有草稿则先要求确认。

单篇主题勾选只替换目录所管理的主题标签，保留其他已有标签，包含隐藏的 `entity:` 标签；合计超过20个时拒绝保存。内部匹配标签由后端维护，不随主题名称改写。原内容管理的原始标签输入仍是完整替换列表，调整时须保留无关旧标签；维护脚本会显式合并。

私人书库首屏提供关键词、来源、主题、类别（含待分类）、笔记回顾和结果列表。关键词按 Enter 搜索，来源、主题和类别选中即生效。“更多筛选”提供收藏、阅读状态、笔记、排序和日期。日期选好后点“应用日期”。“常用视图”可保存或重用已应用的条件。刷新、翻页及从私人文章或历史版本返回书库时保留条件和当前页，重新筛选回到第一页。列表显示每篇文章的分类和主题。私人历史继续包含停用来源和下架文章，与公开列表的可见范围分别处理。

批量整理先在私人书库筛选，再勾选文章或“全选本页”，从选区工具栏打开“批量整理”。默认每页40篇，最多100篇。选择不跨页，切换条件、翻页或重载会清除。批量分类默认“不改变分类”，选择“待分类”则明确清空分类。各主题可选择保留、添加或移除，未指定主题及隐藏实体标签保留。点击“检查批量变更”核对标题和操作，再确认提交。保存成功后按原条件刷新，文章可能移出当前结果。后续页为空时，可点“回到筛选结果首页”继续整理。

批次使用与单篇分类、人工可见性相同的版本检查，任一冲突、不存在、无效输入、标签超限或审计失败均整批回滚。冲突保留选择与操作，可返回调整；“重新载入列表并清除选择”获取新版本后重新勾选。没有实际变化的文章不新增人工覆盖，也不固定原本继承的标签。笔记、收藏、阅读状态、正文和归档均不参与批量修改。

私人书库的关键词还可搜索标题、摘要、当前已保存正文和私人笔记，显示命中字段与上下文。大小写不敏感，多个词均需命中，可分布在不同字段；最多200字符、6个词，`%`、`_` 等按普通文字处理。正文只检索与当前文章精确匹配的已保存快照，历史版本和未保存笔记草稿不参与。搜索不修改公开全文权限，也不向公开索引写入私人内容。

首批分类与标签通过[显式维护流程](deploy.md#首批分类与主题标注)应用，不在 seed 或采集过程中自动执行。仅标题摘要的21篇在清单中标为 `provisional:true`，审计原因注明待补正文复核；此标记是维护依据，不是新增的页面状态。

## 来源

五个初始来源在 `industry/sources.json`；`scripts/seed.ts` 只新增不存在的来源，不覆盖后台修改。暂停来源只停止后续采集，保留历史文章。人工下架是持久决定，重复采集和提取不会恢复公开。

`site_fulltext=false` 时普通文章页只展示摘要和原文链接；设为true后，可在普通文章页直接阅读已采集正文。站主已授权当前本机使用：数据库内五个既定信源均已开启，服务仍仅监听loopback。未取得正文的文章继续显示缺失提示；私人笔记、收藏和历史版本的管理员访问要求保持不变。信源模板仍默认关闭，外部部署的展示范围另行确定。

首次导入上限在 `config._agidawn.initialBackfillLimit`（默认30），月份在 `initialBackfillMonths`（默认12）。普通文章列表按完整匹配结果计数与数字分页，每页25/50/100篇，默认25篇，支持任意跳页，不设总共2,000条的访问上限；私人书库仍使用独立游标。付费提取器的预算在后台“设置”维护，所有付费请求保留回执。
