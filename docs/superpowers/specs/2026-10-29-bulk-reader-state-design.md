# 私人书库批量收藏与阅读状态

用户已确认首批范围并授权在本机 Linux 实现及验证，暂不公开上线。

## 行为

沿用私人书库的本页勾选、全选本页、预览确认、成功按原条件刷新，以及切换筛选/翻页/重载清空选择。新增批量收藏、取消收藏，以及设置待读、在读、已读。收藏与状态可单独指定，也可一起指定；各自默认保留。预览显示所选文章标题和实际请求的两项操作；提交前允许返回调整。

现有分类与主题使用人工覆盖版本，收藏与阅读状态使用私人状态版本。采用同一勾选列表和两种整理内容入口，共用确认流程；一次请求只做一种整理内容。保留现有分类与主题操作作为默认入口，新入口使用可见单选项切换。相比混合提交，这样不扩大事务到文章发布投影；相比独立勾选列表，也不会出现两套选区。

私人批次逐篇携带书库返回的状态版本，最多100篇、不得重复或空选。只改变明确指定的收藏/阅读状态，不改变笔记、分类、主题、标题摘要、可见性、原始正文、快照或归档资源。未选文章不变；不需要改变的文章不写状态或审计，但仍检查其版本。没有状态行表示未收藏、待读、版本0。

## 保存与失败

新增管理员 PATCH `/api/admin/reader/state`，必须登录并携带CSRF，响应不缓存。所有状态与审计在一个事务中保存；任一文章不存在、版本冲突或审计失败均整批回滚。单篇与批量写入按文章锁串行化不存在状态行时的版本检查；批量按文章ID排序加锁，等锁后读取版本，避免相反选区顺序导致死锁。单篇状态接口维持已有版本行为。

冲突保留当前选择、整理内容和操作，提示整批未保存；显式重载获取新版本后重新选择。保存中禁止重复提交。无法确认网络结果时要求先重载核对，不自动重试。会话失效卸载私人控件。沿用既有路由重载错误处理，不增加轮询或缓存。
