# 私人书库关键词搜索

用户已确认并授权：本机Linux实现标题、摘要、已保存正文与私人笔记搜索，与现有五筛选组合；不公开上线。以下是本次具体实施边界，沿用现有技术栈与管理员认证。

- 搜索当前显示的标题/摘要、当前精确匹配快照的正文、当前已保存笔记，不包含未保存草稿或历史正文版本。正文由快照对应HTML派生纯文本，不使用可能陈旧的 `articles.body_text`。
- 关键词不区分大小写，空格及既有中英文相邻边界分词；每个词均需在四种字段之一命中，允许跨字段。最多200字符、6个词；百分号、下划线、反斜杠均按普通文字匹配。空白搜索等同全部。
- 搜索与来源、类别、主题、收藏、阅读状态取交集，保留私人下架/停用来源历史和缺省状态；排序仍为收录时间＋ID。q和其余条件共同绑定游标，换词重新筛选回到第一页。
- 每篇结果显示实际命中字段及最多160字符的纯文本上下文，以React文本渲染；不返回整篇正文或笔记。无搜索时不显示片段。输入有可见标签、说明和移动键盘提示；刷新、翻页、清除正确。
- 仅管理员入口、no-store、失效卸载；私人正文与笔记不写入公开搜索、公开出口、URL日志或模型。GET只携带用户主动输入的关键词及筛选，浏览器地址历史保留这些条件。

实现选择：沿用本地关键词查询。当前96篇规模下按固定批次扫描筛选后的文章，精确核对当前快照后提取正文，复用既有搜索容量限制；只保留一页结果，不截断可检索历史。不新增持久索引，避免新增派生状态与回填；上线前实测本机耗时。数据库索引方案适合未来数据增长后有性能证据时再评估；模型/语义搜索不属于本批。

复用 `storedMaterial` 的映射，通过批量读取函数避免逐篇数据库查询；分词从现有公开搜索函数中提取，公开行为保持不变。无新增依赖、环境变量或数据库迁移。不做批量整理、主题管理器或自动分类。

验收：隔离测试证明四字段、跨字段、长文尾部、展示换版、缺失当前快照、清空/更新笔记、字面符号、五筛选、跨批次分页和权限；真实本机只读搜索，不改用户笔记/正文。完整类型/后端/web检查、独立审查、备份、真实桌面/手机与数据摘要核对后更新本机服务、保存本地提交。
