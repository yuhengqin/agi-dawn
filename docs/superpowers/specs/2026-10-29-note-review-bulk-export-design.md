# 私人笔记回顾与批量 Markdown 导出

用户已授权依次实现：私人笔记回顾入口（有/无笔记、已保存片段与时间、笔记更新时间排序，组合原关键词、五筛选及命名视图），随后批量笔记 Markdown 导出。沿用本机 Linux 工作树，不公开上线。

## 笔记回顾

私人书库增加“笔记”三态：全部、有笔记、无笔记；查询字段 `hasNote=true|false`。未创建、空字符串和只含空白的已保存笔记都归为无笔记，空白判定涵盖 ECMAScript trim 的空白字符。页面始终只展示服务端保存内容，不读取别处页面的草稿。非空笔记返回最多160个Unicode字符的纯文本片段及保存时间；搜索命中私人笔记时沿用命中片段并明确标记，避免同一段重复展示。

增加 `sort=collected|note-updated`：默认最近收录；“笔记最近更新”按非空笔记更新时间倒序，无笔记在后；相同笔记时间按收录时间、文章ID倒序，确保固定数据集分页稳定。游标保留数据库时间精度并绑定原条件、新笔记条件、排序和页大小。关键词扫描和无关键词查询共用排序及游标规则；跨请求期间编辑笔记后需从第一页刷新查看新顺序，不承诺跨请求数据库快照。

“笔记回顾”快捷入口保留当前已应用的关键词和五筛选，设置有笔记与笔记最近更新，清除分页。新条件和排序进入命名视图的保存、摘要、打开与更新；旧视图没有这两项时继续全部笔记、最近收录，无迁移、不改旧记录。显式默认排序在视图中规范化为省略，不产生无效版本更新。公开页面和出口不增加私人片段或时间。

## 批量导出

复用书库本页选区，在选中区域提供独立“导出所选笔记 ZIP”按钮，与已有分类/主题及收藏/状态整理并列，不提交整理草稿。一次最多100篇，只使用当前页明确勾选ID。下载成功或失败均保留选区和整理草稿，切换筛选、排序、分页或重载沿用清空选区规则。导出不触发列表重载。

POST `/api/admin/reader/notes/export.zip` 接收 `{articleIds:string[]}`，仅管理员且须CSRF，返回 `no-store`。拒绝空列表、重复/非法ID、超过100篇与额外字段；任何文章不存在时整包失败，不返回部分文件。所选文章没有笔记时仍导出文章信息与明确空笔记标记，保持选择与文件一一对应；可先使用有笔记筛选排除这类文章。

在一个只读REPEATABLE READ事务内读取全部文章的当前元数据、分类主题、收藏/阅读状态及已保存笔记，每篇复用单篇 Markdown 格式，使用文章ID生成唯一文件名，打包为 `reading-notes.zip`。不加入正文/图片，不改文章、笔记、状态、视图、阅读位置或审计。下载响应回来前发生选区/结果/页面/会话变化时丢弃旧结果并取消在途读取，不让迟到响应触发私人下载。错误保留当前输入，401交由后台边界卸载。

## 验收与交付

先失败测试再实现。后端覆盖空白语义、片段与时间、组合筛选、两种排序的精确时间分页及关键词扫描、视图新旧条件往返与更新；批量ZIP鉴权/CSRF/严格输入、选区内容与单篇格式一致、缺失文章整包失败和全业务/审计只读。浏览器覆盖入口/排序/刷新/分页、命名视图、纯文本安全展示、本页选择下载、重复提交/失败、导航与会话失效后的迟到响应。

无需依赖、环境变量、迁移或回填；不为96篇的小规模查询添加未经证据支持的索引。完整类型、后端、构建和web测试、一次独立只读审查；核对服务、完整备份、暂停worker比对业务摘要，更新本机API/web、真实HTTP及Chromium/WebKit三种宽度验收、恢复服务和timer、smoke并记录结果。真实库已有私人资料只读，非空笔记的交互及并发在隔离数据验证。
