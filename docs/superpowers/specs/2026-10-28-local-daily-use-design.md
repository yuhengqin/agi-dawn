# AGI黎明第二阶段：本机日常使用

用户已授权按运行稳定、内容质量、阅读体验、连续试用的顺序实现和验证，暂不公开上线。基线1cc0939，沿用现有worktree与reader_dev，不触碰原checkout或原运营库。

## 目标与方案

本机每天能稳定获取五个已确认来源的更新；失败原因可查；管理员同页读私人正文、收藏和记笔记；保留未保存草稿的离开确认。公开全文权限与最终分类不变。

本机已验证systemd249用户管理器可用，PostgreSQL容器正在运行。选用用户systemd服务托管现有API/web/worker，复用journal和Restart=on-failure；相比新增Node监督进程，减少一套进程恢复逻辑。完整应用Docker留待生产准备，本阶段不更换运行栈。服务只绑定127.0.0.1，凭据仍在0600的.env，不写入unit。

新增本机CLI提供install/start/stop/restart/status/logs；目标与timer归属于本工作副本，拒绝覆盖其他工作副本的同名unit。停止应用不停止共享测试用PG容器。本机运行显式开启已确认五源采集，默认模板与自动测试仍关闭外部采集、通知和IndexNow。沿用现有来源间隔/重试，不另建调度器。

本地每日备份调用现有--local-only；本地观察报告记录来源采集/正文/资源失败、队列、最新备份及试用起点。报告不含正文、笔记或凭据，保存在忽略目录，记录真实经过时间，不把短时间检查写成一周试用完成。

## 已核实的使用缺口

- 21篇OpenAI工程正文均处理失败，直接抓取根因被缺少可选Jina配置掩盖；应保留HTTP/网络/正文不足的区分，未取得正文明确unconfirmed，刷新失败保留旧正文，不引入付费请求。
- 当前75/96有正文；8篇正文因样式依赖图表partial，另两篇存在资源失败。图片已齐而图表partial时不再建议无效图片重试，不冒称图表已完整。
- 管理员文章页目前只有工具和版本列表，正文在另一个snapshot页。文章页选择与当前材料完全匹配的快照提供私人正文及导出，保留历史入口；不能以任意最新历史快照冒充当前正文。
- 笔记草稿只在内存，导航时应提示未保存、允许取消；失去会话仍清空私人数据。私人书库的筛选控件必须与URL一致。

## 验收

systemd语法验证、真实worker异常终止后恢复、停止后不复活、仅本机监听；五源真实增量采集无重复，错误诊断可查；后台同页私人阅读/笔记、导航保护和筛选保持的浏览器测试；完整类型/后端/构建/网页检查及运行smoke。开启一周观察的起点、自动报告和备份，并注明实际已观察时长。
