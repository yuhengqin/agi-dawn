# 私人书库批量整理

用户已授权在本机 Linux 实现与验证第四阶段批量整理，继续使用现有 `codex/article-reader` 工作树，不公开上线。

在私人书库当前筛选结果页逐篇勾选或全选本页，批量设置分类、添加主题、移除主题。默认每页40篇，沿用现有最多100篇的分页上限；切换筛选、翻页或重载后清除选择，不跨页累积。分类默认不改变，可明确改为“待分类”。每个主题选择保留、添加或移除；其他主题和隐藏实体标签保持原值。

提交前显示所选标题、篇数及变更摘要，确认后保存。整个批次在一个数据库事务内完成；任何一篇版本冲突、不存在、标签超限、无效输入或审计失败，整批不写入。冲突时保留选择和操作，明确提供重新载入列表并清除选择的入口。成功后清除选择并重新执行原筛选；已不匹配的文章自然移出列表。

复用现有分类保存、管理员会话、CSRF、审计和发布投影。按文章 ID 排序加锁，沿用分类与可见性共同的乐观版本；不覆盖并发编辑。只写指定字段，未发生实际变化的文章不新增 override 或审计。保留标题、摘要、可见性、其他标签、原始文章、私人笔记、收藏、阅读状态、正文版本和离线资源；当前本机普通页全文设置不变。

实现取舍：现有逐篇保存不能保证批次原子性；无限“全选所有搜索结果”会引入隐藏选择和长事务。本次采用本页显式选择和专用批量接口，方便核对并限制影响范围。这些属于本次实现决定，可后续扩展跨页操作。

界面沿用现有字体、颜色和原生控件。所有输入有可见标签，操作区分组，点击目标至少48px；保存中禁用重复提交，成功及错误可被辅助技术读取。没有新增依赖、迁移、模型调用、外部采集或线上操作。

验收覆盖完整标签保留、分类清空、幂等空变更、混合版本回滚、重叠并发批次、审计失败、认证与CSRF；浏览器覆盖筛选后选择、确认范围、增删主题请求、翻页清选、冲突保留及过期退出。真实本机数据优先只读验收，写入行为使用隔离测试数据库。
