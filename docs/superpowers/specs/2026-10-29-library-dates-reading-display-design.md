# 私人书库日期筛选与阅读显示设置

用户已授权按顺序实现两项功能，继续在本机 Linux 使用，不公开上线。沿用现有框架、认证、私人状态版本和本页批量操作规则，不新增依赖或数据库迁移。

## 日期筛选

私人书库增加日期依据（收录时间／笔记更新时间）、开始日期和结束日期。允许单侧边界，日期使用北京时间，开始日零点包含、结束日整天包含。笔记日期只匹配有实际内容的已保存笔记，与现有“有笔记”判断一致；空白笔记和未保存草稿不参与。

近 7 天、近 30 天包含今天，点击时按北京时间计算并填入具体日期，随后点击“筛选”应用。快捷选择保留其他尚未提交的筛选输入。可以仅清除日期，也可以清除全部条件。无效日期或开始晚于结束时不能查询或保存视图。

HTTP 字段为 `dateField=collected|note-updated`、`dateFrom=YYYY-MM-DD`、`dateTo=YYYY-MM-DD`；未指定依据时按收录时间。日期与关键词、五种筛选、有／无笔记、排序取交集；日期依据不强制改变排序。游标绑定日期条件，改变日期后旧游标失效。命名视图保存固定日期，不保存“滚动最近几天”；旧视图继续可用。日期条件进入视图描述、分页和笔记回顾入口。本页选择、预览确认、冲突整批不保存、导出及成功后原条件刷新保持现有契约。

方案选择：扩展现有书库查询和视图 JSON；不另设日期查询 API，也不引入滚动日期规则。已有共享北京时间与日期校验工具可复用。

## 阅读显示

在正文前增加可折叠的“阅读显示设置”，覆盖普通文章、私人当前正文和历史正文。字号提供默认／较大／更大，行距提供紧凑／默认／宽松，正文宽度提供窄／默认／宽；一键恢复默认。默认保留现有字号（17px，宽屏18px）、1.8 行距和普通文章760px宽度；自定义字号20／22px、行距1.6／2.0、正文宽度640／760／920px。手机以可用宽度为上限。

方案选择：复用现有浏览器外观偏好存储、跨标签同步和首屏脚本，不新增私人服务端设置表。偏好只包含排版值，当前浏览器记忆；不进入数据库备份，不改变正文、笔记、收藏、分类主题或阅读状态。存储被浏览器禁用时本标签页仍可应用，并明确提示无法持久保存。损坏或未知值回到合法默认值。条款等非文章正文不受影响。

布局宽度同时覆盖普通文章外层和私人正文加目录布局，不只改变 `.prose`。调整排版不重新挂载正文、不改变快照身份。继续阅读后改变排版仍按章节和章节内比例定位；排版变化本身不应写入阅读位置或覆盖笔记草稿。继续阅读按现有章节比例恢复，不承诺定位到相同文字。

以上未由用户逐项指定的具体档位、浏览器存储和界面组织由主代理根据现有实现选择；属于已授权功能的常规实现决策。

## 验收

数据库测试覆盖上海午夜边界、单侧范围、闰日／无效／逆序日期、有内容笔记、条件交集、两种排序与分页、游标隔离、视图保存更新及旧视图。浏览器测试覆盖两引擎、窄屏、快捷范围、筛选／视图／批量操作组合、设置持久化／重置／损坏与禁用存储、三种正文入口和继续阅读。执行仓库 typecheck、后端全套、web build 与全套测试、运行中站点 smoke；真实书库保持，不在真实资料上写测试夹具。
