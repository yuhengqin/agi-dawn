# MiMo 翻译提示词优化与五篇复测

**目标：**保持 `mimo-v2.6-flash`，减少术语漂移、否定关系反转和逐字直译；以 2026-11-07 已保存的五篇固定原文与旧 MiMo 答复进行前后比较。

**设计：**在 `modules/reader/translation/model.ts` 为正文和标题摘要共用语义、文风及按语境区分的术语约束，保留两类输出格式。约束由模型执行，不对译文做全局词语替换。保持分段、请求参数、保护内容和付费回执流程；不增加二次润色调用。

**范围：**更新提示词与其所属使用说明；实验存入独立的 `.data/translation-prompt-2026-11-08/`。保留旧实验、原文和站内已有译文；不自动补译、不切换服务、不修改凭据、预算或数据库结构。

**升级边界：**提示词参与回执身份。未来切换 worker 前须先由旧版处理尚未完成的已发出请求；存在未解决的 `pending/received/unknown` 翻译回执时暂缓切换，不能用新提示词绕过旧回执恢复。本次只做独立实验，不切换 worker。

## 实施步骤

- [x] 阅读正文、元信息调用和既有翻译测试，保存旧请求中的实际提示词与其他参数。
- [x] 更新共用约束与两类提示词；核对 HTML、链接、占位符及纯文本要求仍然有效。
- [x] 运行类型检查、隔离数据库上的翻译集成测试和 `git diff --check`。真实模型质量由授权实验验证，不新增仅检查提示词字面的测试。
- [x] 核对当前本机数据库、全文许可和固定原文身份；通过既有 `llm` 预算／回执只为新提示词请求付费，保留原始答复及 usage。未知结果不直接重发。
- [x] 对同五篇保存新版标题、已有摘要、HTML 和 Markdown，与旧版及原文逐段对照；检查保护内容和生产记录未被改写。
- [x] 对匿名旧／新译文独立评阅，复核已知错误与新增退步，区分已知样本修复和泛化能力；交付结果、证据和限制。

## 验收

五篇均有独立、完整且可审阅的新译文；旧版可追溯，前后模型和非提示词参数可核对。报告逐篇指出术语、否定和自然度是否改善，不能只给综合分。提示词变更不使已完成译文自动失效，worker 加载新代码后仅影响后续请求。
