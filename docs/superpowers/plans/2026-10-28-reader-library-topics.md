# 第四阶段首批：私人书库筛选与主题勾选

**Goal:** 在本机实现来源、分类、主题、收藏、阅读状态的交集筛选，以及私人文章页的主题选择与保存。

**Spec:** 用户已明确授权本批实施；延续第三阶段的6类、14主题与“待分类”。书库保留现有私人访问范围、收录时间排序和缺省待读状态；未公开上线。

**Architecture:** 扩充reader模块已有书库查询与HTTP响应，筛选选项由受保护接口返回；复用现有分类/主题配置。文章分类与主题作为同一表单保存，后台在同一事务/文章行锁内读取完整旧标签并调用 `overrideFieldsTx`；只替换已配置主题标签，保留其他标签、可见性和正文版本。前端继续只调用HTTP。

**Tech Stack:** 现有Node24.22.1、PostgreSQL17、TypeScript、React Router、zod、Playwright；无新增依赖、环境变量或迁移。

## 范围与验收

- 五种筛选均可单独或组合，包含待分类；空选项表示全部，刷新和翻页保留条件，改变筛选从第一页开始。
- 私人书库继续包含下架文章；来源选项包含停用来源，历史阅读不因来源停用丢失。无状态行按未收藏/待读处理。
- 游标绑定全部规范化筛选及limit，坏游标或换条件重用返回400；移除旧未绑定游标格式，不增加兼容分支。
- 私人文章页显示已有主题，分类与主题一起保存，可取消全部；使用原生复选框、可见标签、fieldset/legend、触屏可用尺寸。
- 后台只接受合法主题slug，不接受原始tags；来源继承或人工覆盖中的非主题标签、隐藏标签都保留，超过20个拒绝。
- 分类/主题/可见性共用版本CAS；冲突保留当前选择，提供明确重新载入；重载分类不重载笔记草稿。会话失效沿用后台卸载与登录跳转。
- 不增加正文/笔记检索、主题管理器、自动分类或批量编辑，不改来源、全文许可和既有私人笔记/正文数据。
