# 查找与私人阅读实施计划

> **执行记录：** T06—T09本机交付已完成，见[验收记录](../../reader/acceptance.md)与主计划完成清单。下文保留原计划步骤；实际私人UI由核心admin路由装配，状态/笔记/鉴权行为测试合并在模块privacy测试中，不要求沿用预想文件名。

**Goal:** 让所有公开文章都能按来源、主题、日期与正文查找，并为单一管理员提供跨设备的收藏、阅读状态和简单笔记。

**Architecture:** 公共查询集中在 publication，页面复用阅读器。私人数据存于 `modules/reader`，通过注入现有管理员 guard 的模块路由访问，独立于公共页面数据。

**Tech Stack:** 现有 PostgreSQL 查询与搜索、Fastify、React Router、模块扩展与管理员会话。

**Spec:** [已确认设计](../specs/AGIDawn改造设计方案.md)；[全局约束、依赖和 Q1—Q7 命令](../plans/AGIDawn实施计划.md)。源码路径均相对于未来独立工作副本。

## Global Constraints

普通访客无需账号。公开查询不读私人表；私人响应不进入公共 SSR、搜索、分享或缓存。全文搜索服从与正文相同的权限；无全文权限时，不能通过正文命中推断被限制的内容。继承主计划的日期、排序、分页与缓存约定。

## Review Focus

超过 2,000 条的历史是否可达；主题是否包含非精选文章；长文尾部是否可搜索；过滤条件是否保存在 URL；私人状态是否因身份切换泄漏；两窗口笔记冲突是否保留未保存输入。

## T08 私人阅读与笔记后端

**Files:** 创建 `modules/reader/{module.ts,server.ts,contracts.ts,state.ts,notes.ts}`、`modules/reader/tests/{state,notes,privacy}.test.ts`；修改 `site/modules/{index,server}.ts`、`packages/backend/src/modules.ts`、`packages/contracts/src/admin.ts`、`packages/backend/src/admin/auth.ts`、`apps/api/src/{app.ts,routes/admin-auth.ts}`。新增单语句迁移 `database/migrations/0091_reader_state.sql`、`0092_reader_notes.sql`。

**Interfaces:** 纯类型 `ReaderState = {articleId, starred, status: 'to-read' | 'reading' | 'read', updatedAt, version}`；`ReaderNote = {articleId, text, updatedAt, version}`。首次读取无记录时返回默认状态和空笔记，`version=0`；保存以 `expectedVersion` 做 CAS，成功递增，冲突 409。笔记为纯文本，长度上限 20,000 字符；空文本表示清空笔记，仍保留并发版本。

私人数据属于站主的单一空间，用固定内部 owner 标识，不以可能为空的密码登录 `userId` 或会话 ID 分割。部署只授权站主登录；未来增加其他管理员或读者需要另行设计，不能默认把这套单人数据隔离当作多租户权限。

| 路径 | 行为 |
| --- | --- |
| `GET /api/admin/reader/articles/:id` | 返回该内部文章的状态与笔记，已下架文章仍可读 |
| `PATCH /api/admin/reader/articles/:id/state` | 提交收藏或阅读状态及 expectedVersion |
| `PUT /api/admin/reader/articles/:id/note` | 提交纯文本笔记及 expectedVersion |
| `GET /api/admin/reader/library` | 按收藏、状态筛选私人文章列表，带稳定游标；含下架标记 |
