# 阅读体验与公开搜索优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 11 月 5 日审查发现的全部阅读体验与工程优化。

**Architecture:** 沿用 publication 公开读取与 reader 模块扩展，公开搜索和片段只使用当前有效且获准公开的数据。已有正文的展示修复与今后的提取修复分开，不重新写入私人快照、笔记、阅读位置或翻译原文。

**Tech Stack:** Node.js 24.22.1、PostgreSQL 17、TypeScript、Fastify、React Router、Vite、Playwright。

**Spec:** 本聊天 2026-11-05 的问题核验和优化建议；2026-11-06 使用者授权“优化发现的所有问题”。

## Global Constraints

- 仅以桌面浏览器为设计与专项验收目标；保留共用测试原有覆盖。
- 不提交、推送、公开部署或操作真实私人数据；不触发全量重采集或付费重翻译。
- 保留正文许可实时检查、人工下架、译文精确版本匹配、私人资料隔离及 no-store。
- 共享契约同次更新所有生产方、消费方和测试夹具；旧阅读位置不可静默指向新章节。
- 自动检查清空真实凭据和代理；数据库检查只用本地独立 reader_experience_test。
- 主代理执行语义实现；子代理只承担有界咨询、机械编辑、验证或独立审查。

## Review Focus

- 中英关键词跨原文/译文和元信息/正文命中时，总数、分页和片段一致。
- 原文改版、许可撤销、下架以及 module 未安装时，旧译文不能命中或泄露。
- 有表格的 figure、仅剩小图例、隐藏 SVG 和图注重复，不误报或漏报。
- 过滤目录后既有 sec-N 编号保持，私人阅读位置仍可恢复。
- 认证失效及迟到响应不能重新展示私人状态；新增查看器仍有键盘和焦点归还。
