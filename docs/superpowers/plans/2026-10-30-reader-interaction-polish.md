# 文章阅读交互优化

按已确认的八点方案执行，侧栏与返回行为以最后两次讨论为准。

- 首页文章区域居中，最大宽度 1200px；保留手机边距。
- 无条件或单一条件时不重复展示筛选条；组合筛选支持逐项移除及清除全部，日期合为一项。
- 主题快捷项优先沿用站点配置，再按现有主题顺序补足五项；根据容器空间折叠，顺序稳定；更多入口紧邻快捷项，并显示隐藏的当前主题。
- 搜索提供右侧文字按钮、回车立即提交、300ms 停顿搜索、输入法组词保护、清空同步、加载提示；保留其他条件并重置分页。
- 类别由共享布局提供，全站常驻、默认展开，可收起；以浏览器偏好 Cookie 记忆并参与首屏渲染，刷新不闪动。详情高亮文章类别，探索和我的不高亮类别；手机入口保持独立。
- 日期提供不限、近7/30/90天与自定义，日历和输入联动；草稿确认、取消、单侧范围、北京时间含首尾日、就地错误提示，不设置近一年限制。
- 文章详情不提供显式返回入口；沿用 React Router 按 history key 的恢复机制，验证筛选、分页及两页滚动的后退／前进恢复。

实施顺序：在现有公开阅读测试中增加关键行为 → 共享侧栏与布局 → 主题与筛选 → 搜索 → 日期 → 文档与独立审查。类型检查、数据库测试、Web构建及浏览器测试、运行中站点 smoke 和 Google Chrome 桌面／手机人工流程验收。

已完成实现及验收，见 [交互优化验收](../../reader/interaction-polish-acceptance.md)。真实长文检查额外复现了代码块工具栏在历史恢复后插入导致的重排；安装时机已前移到layout effect，并验证高亮仍按需加载。
