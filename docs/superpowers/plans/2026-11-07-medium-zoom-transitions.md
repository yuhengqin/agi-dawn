# 图片原位缩放过渡实施计划

**目标：** 在 `codex/medium-zoom-transitions` 使用 `medium-zoom` 实现正文图片原位展开、关闭回位，并保留现有查看器功能。用户已选择库并授权实现；本计划记录工程决定，直接在本会话执行，不提交、推送或切换真实服务。

**设计：** `ArticleBody` 将每张图片对应的 DOM 元素传给查看器，按元素而非 URL 区分重复图片。`medium-zoom` 管理动画副本和往返过渡，原查看器管理适应窗口、原尺寸、逐级缩放、平移、切图与键盘。关闭开始时测量当前画面和当前正文图片位置，完成过渡后才卸载、解锁滚动和归还焦点；切图不回到最初图片。正文目标离开视口或已移除时使用淡出，避免长距离飞越或跳动。减少动态效果直接完成状态切换。

**范围与约束：** 仅桌面验收；保留既有触屏行为。普通正文、私人当前正文和历史正文共用入口，权限与资源 URL 保持原约定。使用独立 worktree 与假 API 验证，不覆盖原目录的运行中构建和未提交改动。

## 验收关注点

- 关闭动画期间图片、模态焦点和滚动锁仍存在，动画完成后无副本或隐藏样式残留。
- 相同图片 URL 的不同正文元素各自定位；切图后的原位目标不依赖首次打开索引。
- 放大、滚动和平移后的可见内容连续交接，不先跳回适应窗口。
- 动画未完成时 Esc、重复关闭、快速切图和组件卸载不遗留异步状态。
- 窗口调整不意外关闭查看器；减少动态效果保留所有功能。
