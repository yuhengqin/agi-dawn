# 阅读内容与控件优化实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 按任务实施；调查与最终审查可委派只读角色，主代理负责语义修改。

**Goal:** 修复本次确认的摘要、正文杂质及桌面阅读交互问题。

**Architecture:** 采集阶段清理已证实的来源组件，元信息翻译使用纯文本契约；公开读取只做确定性内容规范化，不调用模型，不改变正文版本或私人快照。前端保留原生表单语义，统一来源筛选外观，压缩显示设置并简化目录展开。

**Tech Stack:** Node.js 24.22.1+、TypeScript、Fastify/PostgreSQL、React/React Router、CSS、Playwright Chromium/WebKit。

**Spec:** 本聊天中已审查并由用户确认的方案；具体范围与验收如下。

## 已确认范围与约束

- 修复 RSS 尾注、译文新增链接标签、来源品牌摘要、残缺实体及已证实的卡片重复；不使用摘要20字符门槛或全局短语去重。
- 清理来源头部重复日期与外链隐藏提示，保留多作者署名、正文中的日期和同词内容。
- 标题锚点控件不作为正文图片；图例保留行内语义，普通插图继续居中。
- 来源控件字号、箭头和选中态统一；保持 GET、筛选保留和无脚本提交。
- 阅读设置使用原生 radio 分段组；默认时禁用重置，仅在需要时展示图表提示恢复入口。
- 嵌套目录默认展开，可手动收起当前分支；父项提示被折叠的当前位置。
- 无主题和长作者元信息为原文链接预留空间；公开页面省略收藏未开放占位。
- 保留已有分页蓝色规范；未复现的垂直偏移不添加修复。
- 仅验收桌面；不提交、推送或公开发布。用户随后明确授权备份后定向修复存量数据，按部署约定完成本机服务停机、维护与恢复；不进行付费重译。

## Review Focus

- Atom 纯文本中的 `<model>`、合法 `&`、短中文摘要不能被误删。
- 已存译文与原文版本匹配，不因显示规范化触发模型或破坏图片快照匹配。
- 多人署名、有效图例、普通插图及正文中的日期/外链说明得到保留。
- 手动折叠目录不被滚动强制打开，键盘焦点和当前位置仍可判断。
- 设置恢复、跨标签同步、存储失败与私人正文复用继续正常。
