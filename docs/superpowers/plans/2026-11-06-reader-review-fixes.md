# 阅读优化验收缺口修复 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话内完成；用户已授权修复三项已复现问题。

**Goal:** 修复原文行内标签导致的搜索漏检、摘要清理后的无证据命中，以及页首/文末点赞并发覆盖。

**Architecture:** 搜索仍在同一 SQL 快照内完成过滤、计数和分页；使用当前正文 HTML 的可见文字与展示规则清理后的摘要匹配，结果片段使用相同文本。同篇点赞入口由已有 EngagementProvider 共享在途请求状态。

**Tech Stack:** Node.js 24.22.1、PostgreSQL 17、TypeScript、React、Playwright。

**Spec:** 本会话 2026-11-06 的三项验收结论及用户“修复一下你发现的这三个问题”。

## Global Constraints

- 不改变全文许可、译文版本匹配、私人资料隔离及 no-store；不重采集、重翻译或写入真实数据库。
- 沿用现有契约和桌面浏览器目标，不增加产品功能、依赖或自动重试。
- 隔离构建/测试，验证后迁回主工作区；不提交、推送或切换常驻服务。

## Review Focus

- 原文行内标签连接文字，块标签仍分词，HTML 属性不成为正文命中。
- 原文/译文摘要的尾注、来源占位和截断清理与展示一致，保留有效正文及原文标题命中。
- 多字段混合查询、分页总数、来源/主题名称和片段采用一致的匹配规则。
- 许可撤销或译文失效即排除正文；旧的正文纯文本索引不覆盖现存 HTML 的可见文字。
- 点赞成功、失败及跨入口操作共享同篇在途状态，其他文章仍可独立操作。
