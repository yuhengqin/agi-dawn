# 文章详情阅读体验实施计划

> 执行方式：主代理在独立 worktree 内实现，完成后独立审查；使用 executing-plans、test-driven-development 与 verification-before-completion。用户已确认推荐方案并要求直接实现，无需再次设计审批。

**Goal:** 让普通文章页具有可跟随、可展开的目录、正文范围进度、清晰元数据和紧凑语言切换，并通过真实 Chrome 验证。

**Architecture:** 保留现有 HTTP 数据契约与文章布局。复用当前章节识别及锚点跳转，把已有私人阅读的纯位置测量函数提为前端共享工具；普通页只在当前页面保持位置，不访问私人位置接口。

**Tech Stack:** React 19、React Router 8、TypeScript、Tailwind/CSS、Playwright Chromium/WebKit；Node 24.22.1。

**Spec:** 用户在本聊天批准的“顶部细线 · 推荐”方案：桌面右侧层级目录与当前章节、手机吸顶目录；顶部 2px 站点青色进度线和目录百分比；标题下来源/日期/作者分层；正文工具栏分段式中文/原文、阅读设置、外部原文入口。

## 约束与设计决定

- 不改模型、翻译生成、采集、数据库、依赖或站点全局导航；所有付费和采集开关保持关闭。
- 保留默认中文、原文来源、日期缺失时的“收录时间”、主题筛选、互动统计、私人工具和显示偏好。
- 目录点击替换锚点，不新增后退历史；键盘可操作，减少动态效果时即时跳转。当前分支自动展开，其他分支可手动展开。
- 正文顶部抵达阅读线时为 0%，正文末尾进入视口底部时为 100%；短文完整可见时为 100%，不以页脚和私人工具计算进度。进度不修改已读状态。
- 顶线与目录百分比共享正文范围测量，滚动通过 RAF 合并更新；避免两套进度算法在工具栏折行或短文时产生差异。进度直接反映阅读位置，不增加动画。
- 翻译按原块替换，但独立生成目录，缺少永久章节身份。只有两种目录 id/level 序列相同时按同序章节内比例恢复；不同结构或无标题时按正文比例恢复。不承诺逐句对齐。
- 排版变化、延迟图片导致高度变化时重算进度；切换后的位置恢复在读者主动继续滚动或导航后停止。

## Review Focus

- 标题结构不一致、没有标题、部分译文：位置恢复不能落到错误序号章节。
- 工具栏折行、手机安全区、阅读设置弹层：章节标题不能被遮住，目录和控件不能横向溢出。
- 长目录、h4、短末章：当前项和展开按钮不能被目录滚动吞掉。
- 图片/代码增强改变正文高度：进度和恢复点必须更新，用户继续操作后不能被拉回。
- 浏览器后退/前进、换文章、无正文：不能遗留进度、语言状态或恢复观察器，也不能损坏私人继续阅读。
