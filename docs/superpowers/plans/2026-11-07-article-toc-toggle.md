# 普通文章目录折叠实施计划

**目标：** 参考 [Claude Code Docs](https://code.claude.com/docs/en/overview) 的右侧目录开关，在普通文章详情页提供整栏收起与展开。

**设计：** 目录默认展开；收起后只留带向左箭头与目录图标的紧凑按钮，释放右侧目录栏的空间。正文左边缘保持不动，向右填满让出的空间；当前窄／默认／宽阅读偏好决定展开时的正文宽度，折叠后在各自宽度基础上扩展。开关仅影响当前文章，刷新或切换文章后重新展开，不新增持久化偏好。

**实现选择：** 在文章入口管理状态，现有目录组件保留挂载并隐藏导航，从而保留章节子树的手动折叠状态。复用现有阅读点捕获与恢复，不新增依赖。按钮使用原生 button、明确的名称、aria-expanded 与 aria-controls，切换后保持焦点。

**范围：** 仅普通文章桌面右侧目录（现有1280px断点）。较窄桌面的正文前目录入口继续使用现有行为；无目录文章不显示开关。专注模式继续隐藏目录并保留当前布局占位。私人正文、后端、数据库及本机服务不在变更范围。
