# 阅读交互优化实施计划

> **For agentic workers:** 使用 superpowers:executing-plans 逐项实现，并在最后独立审查。

**Goal:** 修复已由 Chrome 复现、使用者确认优化的前三项问题：图片缩放跳跃、代码字号固定、搜索到详情缺少衔接。

**Architecture:** 保留现有 Lightbox 与阅读偏好，通过当前显示比例缩放并保持视野中心。列表链接携带有界关键词与命中提示，详情只在当前公开内容中寻找和高亮匹配；原文命中且当前显示译文时指向既有来源链接。

**Tech Stack:** React、React Router、TypeScript、CSS Custom Highlight API、Playwright。

**Spec:** 本次对话的实测结果及使用者指令“优化前三个问题，忽略【长列表调整每页篇数】的问题”。

## 约束

- 仅桌面验收；不改分页，不新增来源或扩大全文展示权限。
- 不修改后端契约、真实数据或付费排程，不提交或发布。
- Node.js 24.22.1；构建和假 API 测试使用隔离副本，避免覆盖 4040 服务的构建。

## 审查重点

- 超大横图、长竖图、平移后缩放及切换图片均保留正确比例与可达区域。
- 搜索跨行内标签，代码延迟着色后仍可定位，不计入代码工具文案或行号。
- 详情正文许可撤回、原文/译文不一致和旧命中信息不会错误展示隐藏正文。
- 搜索定位只由显式点击触发，不覆盖后退/前进的滚动恢复。
- 字号切换、存储同步与恢复默认仍作用于代码及行号。
