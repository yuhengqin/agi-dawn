# 第四阶段：批量收藏与阅读状态验收

2026-10-29（Asia/Shanghai）。基线 `c27d7ea`，继续在 Linux 本机 `codex/article-reader` 工作树实现并更新运行版本。未推送或公开上线。

## 使用

打开[私人书库](http://localhost:3000/admin/reader)，搜索或筛选后逐篇勾选，也可“全选本页”。在批量整理的“整理内容”选择“收藏与阅读状态”，可收藏、取消收藏，或设为待读、在读、已读。两项默认保留，可单独修改或一起设置。

点击“检查批量变更”核对文章标题、篇数以及收藏/阅读状态操作；可返回调整，确认后才保存。成功显示所选和实际变更篇数，按原搜索与筛选刷新，不再匹配的文章移出列表。选择仅限本页，最多100篇；切换筛选、翻页或重载会清空，取消选择不提交。

现有“分类与主题”操作保留为默认入口，两种整理内容共用选区，一次提交其中一种。未指定的状态字段、未选文章、私人笔记、分类、主题、标题摘要、可见性、正文和归档资源保留。新状态只在管理员入口可用，不进入普通文章响应。

## 保存与失败

新增 `PATCH /api/admin/reader/state`，复用管理员认证、CSRF和 `no-store`。逐篇携带私人状态版本，与分类版本分开；没有状态行按未收藏、待读、版本0处理。拒绝空集、重复文章、超过100篇、非法ID/版本/状态、未知字段及未指定操作。

单篇与批量写入都锁定文章行，以协调尚未创建状态行的版本检查；批量按数据库ID顺序取得全部文章锁，等待后再读取状态版本。版本检查、变化状态写入和审计同事务提交，任一缺失、过期或审计失败均整批回滚。无变化也检查版本，但不创建默认状态、不增加版本或审计；单篇接口继续沿用原有版本行为。

冲突保留所选文章、整理内容和操作，提示整批未保存；显式“重新载入列表并清除选择”后再勾选。保存中禁用重复提交。网络结果不明确时先重载核对，不自动重试；会话失效卸载私人控件并跳转登录。
