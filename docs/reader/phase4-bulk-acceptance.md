# 第四阶段：私人书库批量整理验收

日期：2026-10-28。基线 `0a988e2`，在 Linux 本机 `codex/article-reader` 工作树实现并更新服务，未推送或公开上线。

## 使用

打开[私人书库](http://localhost:3000/admin/reader)，搜索或组合筛选后逐篇勾选，也可“全选本页”。默认每页40篇，沿用最多100篇的分页上限。选择仅限当前页，切换筛选、翻页或重载会清除，不会暗中包含其他页面的文章。

批量分类默认“不改变分类”，“待分类”表示明确清空。每个主题可以保留、添加或移除，其他主题及隐藏的实体标签保留。点击“检查批量变更”核对所选标题、篇数及变更摘要，可以返回调整，确认后才写入。成功显示实际变更篇数并按原查询刷新，不再匹配的文章会移出当前结果。

分类、主题沿用全站文章元数据，普通文章页与列表同步更新；私人笔记、收藏、阅读状态仍需登录，也不会被此操作修改。原始文章、人工标题和摘要、可见性、正文版本与归档资源均保留。当前普通页已采集正文的展示设置不变。

## 保存边界

`PATCH /api/admin/reader/classification` 只允许管理员及有效CSRF。输入逐篇携带列表中的分类版本，与单篇分类和人工可见性共用乐观检查。按文章ID排序锁定所选文章，等待完成后再读取版本；信源继承标签在事务内保持一致。

复用 `overrideFieldsTx`，全部文章、发布投影及审计在一个事务中提交。任一冲突、文章不存在、无效分类/主题、标签超过20个或审计失败均整批回滚。拒绝重复文章、重复主题、同时添加和移除同一主题、空操作及超过100篇的请求；只修改实际变化的字段。无需变化的文章不新增人工覆盖或审计，不固定原本继承的标签。

冲突时保留当前选择和操作，可返回调整；“重新载入列表并清除选择”获取新版本后重新勾选。没有自动重试或静默覆盖。保存期间禁用批量控件并防止重复提交；网络异常时提示先重载核对结果。
