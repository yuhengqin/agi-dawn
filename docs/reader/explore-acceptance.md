## 当前行为

- 桌面侧栏独立显示类别，顶部主题导航包含两列“更多主题”浮层；手机提供类别与主题两个浮层入口。选择、点击外部、再次点击触发器或 Esc 均关闭浮层；Esc 将焦点还给触发器。手机底栏保留文章、探索、我的。
- `/explore` 默认按主题浏览，原生链接切换到 `/explore?view=sources`；刷新、浏览器返回和关闭 JavaScript 都保留可用入口。
- 桌面保留三至四列卡片，手机为整行链接。主题展示总篇数、近30天篇数、最新文章及更新时间；来源展示说明／地址、已收录篇数和最近文章时间。不恢复“访问原站”按钮。
- 卡片、文章列表来源及文章页所属主题／来源统一进入 `/?topic=...` 或 `/?sourceId=...`。标题始终为“文章”，控件展示实际筛选范围。
- 首页文章标题连续排列并按发布时间倒序；日期按上海时区显示，缺少发布时间时显示收录时间。2026-10-31 的[公开阅读优化](public-reading-polish.md)增加最多两行摘要，优先译文，缺少时回退原摘要。类别和主题可交集筛选；类别的“全部”只移除类别条件，主题的“全部”只移除主题条件，两者保留搜索、来源和日期条件。切换筛选条件丢弃旧 cursor，从第一页开始；旧 `/all` 地址保留查询条件跳转到首页。
- 旧 `/topics`、`/sources` 转到对应探索视图，旧详情地址转到文章列表并保留有效查询条件。编码控制字符和非法路径不产生重定向。
- 移除旧结果页面、专属主题分享卡与独立主题详情读取接口。站点地图只列出探索两种视图和文章等正式页面；筛选结果继续 noindex。已退休的会话导航记录在下一次记录页面时清理。
- 原探索入口改造保留主题管理、来源权限、私人书库及微秒精度游标；当时未新增依赖、迁移或模型调用。
