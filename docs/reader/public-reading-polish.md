# 公开阅读页面视觉优化

2026-10-31。按站主确认的方向优化列表与普通文章页；阅读数、点赞数和收藏占位继续展示。旧版“不展示摘要”的选择随本次更新调整。公开部署、账号体系和采集授权不属于本次改动。

## 设计

- 沿用青色品牌和现有字体选择。页面底色 `#faf9f6`、内容面 `#ffffff`、主文字 `#202a30`、辅助文字 `#59656b`、分隔线 `#dfe4e1`、强调色 `#176b75`；深色沿用现有语义变量。
- 首页采用单一内容面，搜索与主题导航在上，文章按时间连续排列。标题加重，显示已有摘要（译文优先，缺译文时原摘要），最多两行；缺摘要时不制造占位。来源、上海日期、完整性和互动统计继续提供。
- 文章采用正文与目录相邻的双栏。没有目录时正文居中；没有内容的左辅助栏不占位。默认正文仍为 760px，保留窄／宽偏好，手机按可用空间显示。
- 标题下集中显示来源、作者、日期、统计与原文链接，主题按空间换行。元信息下保留一条分隔线，导语使用灰色竖线与正文区分。阅读设置已移至右下角，新增专注模式，详见[文章阅读工具调整](article-controls.md)；完整性提示保留。
- 使用现有 SVG 图标统一外链和展开符号，保持清楚的图形大小与键盘焦点；点击区域不随图形缩小。

参考站的内容层级与相邻分区适合此站；不引入其推广栏、推荐算法或大图广告。只调颜色或只换图标无法解决空栏、列表信息不足与阅读顺序的问题，因此先调整结构。

- 真实内容在 320、390、1024、1366、1920px 下无横向溢出，明暗主题无脚本异常；额外用 Chromium、WebKit 检查 960／961、1279／1280px 目录切换边界、无目录居中，以及窄／默认／宽阅读偏好。
- 不同语言的目录结构不一致时，阅读比例保持测试使用可见按钮的鼠标坐标点击，并检查点击位置可达、语言确实切换。追踪确认原 Locator 点击会在点击前自动滚动 sticky 控件，造成 40% 变为约 28.8%，因此修正测试操作，保持原比例断言。
- 完整回归进一步暴露快速连续切换的另一问题：全局 reduced-motion 样式把所有元素的过渡时长设为 `0.01ms`，给原本静态的 `max-width` 也加上了过渡。目录出现后正文先变窄、再恢复宽度，再次点击恰好发生在重排与位置恢复之间时，把临时的 59.4% 当作新位置。现将该模式的过渡时长设为 `0s`，不改变阅读定位逻辑；在 Chromium、WebKit 各五次新页面中连续切换四次，共40次切换均保持约40%。
- 一轮完整回归的 WebKit 私人阅读页曾在 `visit` 等待 Router 初始化时超时；未改动该页面或断言，随后独立复查两浏览器的私人阅读与上述语言切换共4项通过。该初始化超时未确定原因，不能表述为已修复。
