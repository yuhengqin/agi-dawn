# 文章数字分页

日期：2026-10-31（Asia/Shanghai）。分支 `codex/article-pagination`，独立工作树 `/home/laoq/.codex/worktrees/article-pagination/AGIDawn`。

## 行为

- 普通文章列表显示当前筛选匹配总数、当前篇数范围，每页25/50/100篇，默认25篇。
- 列表底部左侧依次显示每页篇数与范围统计，右侧放页码和按需显示的跳页控件；空间足够时合为一行，不足时按组换行，不使用通栏底色、外框及竖向分割线。最多9页时完整显示（包括7页的常见情况）；更多页时显示首尾、当前页及邻近页码，用省略号分隔。前后页只显示箭头图标，保留可访问名称、快捷键悬浮提示和44×44px点击区域。手机保留相同页码并换行。
- 统计显示当前篇数范围和匹配总数，数量选择支持每页25/50/100篇。页码全部可见时隐藏跳页；实际出现省略号时，提供可编辑的当前页/总页数，输入目标页后可回车或点击“跳转”，失焦不跳页。第一页的上一页、末页的下一页保持不可操作并明显淡化；页码、输入框和按钮保留至少44px点击高度及键盘焦点提示。列表头保留总数与范围。空结果或单页不显示页码导航，仍保留总数和数量选择。
- 页面大小、数字链接和跳页均使用GET，筛选保留在URL；关闭JavaScript也可用原生链接和表单。更改筛选或每页篇数回到第一页，清除全部筛选保留每页篇数。
- 刷新和浏览器历史保留页码、每页篇数及筛选；文章详情返回时仍由现有ScrollRestoration恢复历史条目的位置。
- 公开接口 `/api/site/articles` 使用 `sourceId/category/topic/from/to/q/page/limit`，返回 `{items,total,page,limit,pageCount}`。正整数页码超出末页时返回末页数据；空结果为page=1、pageCount=0，网页规范化对应URL。
- 总数与当前页来自同一个SQL快照，沿用公开权限、来源全文许可和现有搜索限制；数据库按完整时间精度和文章ID倒序排列。
- 普通列表不再接受cursor或25/50/100以外的limit。私人书库、采集游标和已有资料保持原约定。
- 页码描述当前结果集合，新收录、撤回或重新排序可改变某页内容，不承诺永久固定的分页快照。

## 2026-11-01 分页体验与交互优化

- **纵向间距与视觉流收紧**：将页码导航栏底边距从 16px 调整为 12px，使上方的页码指示与下方的数量/容量/跳页控制面板视觉关联更紧凑，浏览节奏更清晰。
- **交互式省略号跳页（Interactive Fast Jump）**：将静态文本省略号转为具象链接，支持快速前后跳步（±5页），hover 或 focus-visible 时由 `…` 切换为 `«` / `»`，并具备完整的无障碍 `aria-label` 与 `title` 辅助文案。
- **桌面键盘快捷键导航**：监听键盘快捷键，在未聚焦输入框/表单/对话框时，支持通过 <kbd>←</kbd> 或 <kbd>h</kbd> 触发上一页，<kbd>→</kbd> 或 <kbd>l</kbd> 触发下一页。
- **客户端链接预取**：为所有分页链接（数字页码、上一页/下一页、快速跳步链接）配置 `prefetch="intent"`，鼠标悬停或焦点移入即由 React Router 自动预载对应页面资源，提升客户端切页即时性。
- **跳页输入微交互**：页码输入框增加 `onFocus` 自动选中当前数字 (`select()`) 和 `autoComplete="off"`；跳转按钮增加快捷提示文案。
