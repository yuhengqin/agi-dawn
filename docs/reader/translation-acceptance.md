# 新收录文章自动翻译

用户选择自动翻译新收录的外文全文，并将中文译文扩展到列表标题与详情标题、摘要。翻译保留原文，不恢复评分、写作或热点流程。

## 使用方式

- 正文取得后由 worker 每五分钟处理。新建文章时登记资格，已有文章不会因重抓、重新发布或部署自动补译。
- 列表和详情优先使用已保存中文译文；普通文章在元信息行提供来源原文链接。尚无译文时继续显示原文，翻译完成后刷新查看。2026-10-31的[阅读工具调整](article-controls.md)移除了站内中文／原文切换，下方早期验收记录保留当时行为。
- 标题和摘要独立处理已有及新收录的公开文章，不依赖正文或全文许可；每轮最多30篇。中文字段保持，缺少摘要不生成摘要；源标题或摘要变化后旧译文立即隐藏，随后翻译新版本，不重译已有正文。
- 保留原文 HTML 容器、代码、媒体和链接；嵌套列表、引用中的直接文字也参与翻译。缺失受保护内容的片段重试一次，仍失败则保留原文并提示不完整。
- 来源当前全文许可、人工下架及公开范围对原文和译文一致生效。译文图片对应原文当前快照，私人快照、笔记、ZIP 和阅读位置保持原文身份。
- 没有恢复旧站模型管理面板。模型由运行环境的 `LLM_BASE_URL/LLM_API_KEY/LLM_MODEL` 配置；严格 `MODEL_CALLS_ENABLED=true` 才发送请求。

## 费用和恢复

全部请求经过现有回执和 `llm` 预算。初始化命令见 [部署](../deploy.md#新文章自动翻译)，保留人工限额；缺少预算时不调用。正文保存失败或多批翻译被预算暂停后复用已收到的答案；未知结果等待原有恢复机制放行，不直接重发。关闭、预算等待、进行中和未知结果不消耗文章尝试次数，单篇处理失败三次后停止自动重试。

每批约3500字符，单篇上限60000字符；超出范围或失败的片段保留原文，并标记译文不完整。
