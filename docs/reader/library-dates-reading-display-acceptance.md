# 私人书库日期范围与阅读显示验收

日期：2026-10-29；环境：本机 Linux、Node24.22.1、PostgreSQL17、Chromium/WebKit。未公开上线，无新依赖、数据库迁移或采集策略变化。

## 使用与语义

- [私人书库](http://localhost:3000/admin/reader)选择日期依据：收录时间或笔记更新时间，填写开始／结束日期，允许单侧边界。按北京时间包含开始日零点和结束日最后一刻；实现使用次日零点排他上界，保留数据库微秒精度。
- 近7天／近30天包含今天，点击时填入固定日期，保留其他筛选草稿，随后点击“筛选”应用。“清除日期”只清除两端日期，清除全部条件仍使用“清除筛选”。
- 笔记日期只匹配有实际内容的已保存笔记，与有／无笔记判断一致；空白笔记、未保存草稿不参与。日期依据不自动改变排序，与关键词、五种原筛选、有／无笔记及两种排序取交集。
- 日期随分页、刷新、笔记回顾和命名视图保留；日期变化使旧游标失效。命名视图保存具体起止日期，不是滚动规则；旧视图仍可打开。批量操作与导出继续只作用于本页所选，预览确认、冲突整批不保存及原条件刷新沿用原规则。
- 普通文章、私人当前正文、历史正文都有可折叠“阅读显示设置”。字号默认／较大／更大，行距紧凑／默认／宽松，宽度窄／默认／宽；可恢复默认。默认字号17px（宽屏18px）、行距1.8；较大／更大为20／22px，紧凑／宽松为1.6／2.0，正文宽度640／760／920px，实际受可用空间限制。
- 浏览器记忆显示偏好并同步同源标签页，首屏即应用；损坏值回到合法默认值，存储拒绝时本标签仍可调整，并提示未能记住。条款页面不受文章设置影响。显示偏好不进入数据库备份；换浏览器或清除站点数据后重新设置。
- 私人阅读按章节与章节内比例保持位置，不承诺同一句文字。调整排版本身不写阅读位置，不改正文版本、笔记草稿、分类主题、收藏或阅读状态；后续真实阅读仍沿用原有自动保存和冲突处理。
