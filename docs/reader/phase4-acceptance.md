# 第四阶段首批：私人书库筛选与主题勾选

日期：2026-10-28。在 Linux 工作副本 `codex/article-reader` 实现并更新本机运行版本，本批只交付私人书库组合筛选与文章页主题勾选。继续使用已确认的6类＋待分类、14主题，不公开上线，不推送代码。

## 使用方式

[私人书库](http://localhost:3000/admin/reader)可按来源、类别、一个主题、收藏、阅读状态同时筛选，条件取交集。空选项表示全部；刷新和翻页保留条件，重新筛选从第一页开始，“清除筛选”返回全部。停用来源和已下架文章的私人历史仍可访问；没有阅读状态记录的文章按未收藏、待读处理。

私人文章页的“文章分类与主题”支持勾选多个主题，也可全部取消，与分类一起保存。保存只修改已配置主题标签，保留其他标签、人工标题/摘要和可见性；超过20个标签会拒绝。分类、主题及其他人工编辑共用版本检查；保存冲突保留当前选择，点击“重新载入分类与主题”不会清除笔记草稿。主题词表新增仍通过 `industry/topics.json` 配置并重启API；分类可在后台新增、改名。

## 验收中处理的问题

截图复核发现新控件的48px触控高度没有生效。构建CSS中不存在对应规则，原因是Tailwind只扫描模块 `web.tsx/web/`，没有扫描reader的 `pages/` 与 `components/`。将这两个视图目录加入样式扫描范围后重建，三种宽度的筛选控件、主题标签与保存按钮均达到预期高度；重新检查布局、完整web测试和smoke通过。没有为样式尺寸增加永久测试断言。
