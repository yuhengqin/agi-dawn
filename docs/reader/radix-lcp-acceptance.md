# Radix 交互迁移与 LCP 基线

2026-11-01。将后台 `ReasonDialog` 和图表提示使用的 `Menu` 迁移到 Radix Primitives，保留既有外观和业务接口。对照基准为 `7f2e051`，性能与交互验收使用独立工作副本的生产构建；随后按站主要求在主工作副本重建并启用本机生产 web。

## 交互约定

- `ReasonDialog` 使用 `@radix-ui/react-dialog` 1.3.1 管理 Portal、模态焦点、Esc、遮罩关闭和生命周期。保留原因必填及 trim、busy 禁止重复确认、提交返回 false 时保留草稿、再次打开清空、取消不提交。标题和说明具备可访问关联。
- 对话框由现有后台按钮控制，打开前显式聚焦按钮，关闭后返回该按钮；这也覆盖 WebKit 鼠标点击按钮不自动聚焦的情况。预算对话框显式保留原表格带来的右对齐和 13px 基础字号，避免 Portal 改变外观。
- `Menu` 使用 `@radix-ui/react-dropdown-menu` 2.2.1，明确设置 `modal={false}`。保留现有按钮和菜单样式、选择回调及链接属性，交由 Radix 处理定位、碰撞避让和菜单导航。ArrowDown 打开首项，ArrowUp 打开末项，Home/End 和方向键导航；Tab/Shift+Tab 从触发器继续正常页面遍历。外部控件仍可直接点击。
- 迁移移除了这两个组件原有的全局关闭监听、手写定位和 Motion 对话框外壳。现有阅读浮层、Lightbox、无 JavaScript 的 details、正文清洗和图片加载属性保持原状。

## 图片优先级结论与局限

五类样本只有正文开头图片页面的 LCP 是图片，其余均为文字。该图已经出现在首份 HTML，未懒加载；请求在导航约 58–63ms 开始，浏览器优先级从 Low 提升到 High。限速下迁移前约 710ms 下载完成，迁移后约 797ms 完成。

本次保持图片优先级不变。现有证据支持下一步只对可靠识别的首屏关键图做 `fetchpriority="high"` 对照实验，尚不足以制定“所有首图高优先级”的规则，也没有证明提示一定改善 LCP。若实施，应在在线正文输出、归档地址替换后施加本站策略，覆盖存量正文且不改写正文快照、译文版本或阅读位置。

这是本机实验室基线，不是线上用户指标。站外资源（包括 `storage.ghost.io`、`storage.googleapis.com`）被拦截，API 与资源存储位于本机，服务端缓存没有重置；CDP 限速结果受本机服务器和请求拦截路径影响。未覆盖真实公网/CDN、冷服务端缓存、其他阅读字号/宽度、所有文章或 WebKit LCP，不据此宣称公网性能达标。
