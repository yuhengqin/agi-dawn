# 文章阅读工具调整

2026-10-31。按站主给出的掘金浮动工具与 Anthropic 专注模式参考，调整普通文章页。

## 约定（含2026-11-13更新）

- 标题下保留元信息与摘要之间的一条横线，移除语言切换与正文类型工具栏。默认优先展示已有中文译文，明确标注“中文译文”；原始表示中的中文内容标注“中文正文”。正文契约用 `language` 表示原始／站内翻译身份，用 `contentLanguage` 表示识别出的内容语言；搜索证据和未完成翻译提示仍依据前者。打开原文位于元信息行。来源、作者、日期和阅读信息与主题分行。
- 阅读显示设置收进右下角的省略号按钮，面板向左上展开；页面滚动时收起面板，面板内部滚动及设置引起的重排仍可正常使用。下方依次为专注模式、主题切换、返回顶部。桌面共享布局给工具栏预留独立空间，正文、目录和列表分页均避让；专注模式保持同一占位。手机继续避开底栏与安全区。
- 字号、行距和宽度使用原生三档单选组，支持方向键与浏览器偏好同步；代码块与行号也随字号调整，默认/较大/更大分别为13/14.5/16px，代码工具栏字号保持。全部默认时禁用“恢复默认显示”。只有图表提示已被永久禁用时才显示恢复入口，恢复后保留面板内焦点。
- 嵌套目录默认展开，长目录使用现有内部滚动；当前章节及祖先也可手动收起，滚动不强制重新展开，父项提示被隐藏的当前章节。
- 侧目录根据实际阅读容器是否容得下当前正文宽度（窄640px、默认760px、宽1200px）及目录决定出现，不使用固定1280px断点；空间不足时改用正文前的目录入口。整栏目录默认展开；收起后隐藏目录标题、进度与链接，仅保留向左箭头和目录图标的展开按钮，正文左边缘保持在展开时的位置，向右填满目录让出的空间；窗口空间不足时按可用宽度收敛，正文继续避让右下浮动工具，再次展开恢复原宽度。切换保持章节内阅读位置、子章节手动折叠状态与按钮焦点。状态仅属于当前文章，刷新或切换文章后重新展开；无目录文章不显示按钮。专注模式隐藏当前目录或展开按钮，并保留当前布局占位。
- 普通文章自然滚动以视口上方四分之一附近作为章节激活线；点击目录仍按既有锚点落点定位，并暂时保持点击目标，避免短章节立即抢走高亮。私人快照的定位语义保持。
- 公开元信息不展示尚未开放的收藏占位；互动、阅读时长与译文标识整体分组，长作者完整可读，主题仍单独展示并按空间换行。
- 专注模式仅作用于当前文章，隐藏侧栏、目录及手机导航，保持正文原有位置和宽度，按钮选中后变深色；再次点击或按 Escape 退出并保留阅读位置与宽度。已有浮层优先消耗 Escape。离开文章后恢复普通页面。
- 图表提示区分“部分图表未保存”和“部分图表可能显示不完整”；完全缺失的图在原位置另有可点击原文入口，隐藏总体提示不会隐藏这一入口。有具体问题时支持悬停、键盘聚焦或点击查看去重后的详情。可用 Esc 关闭详情。× 打开“本次关闭直到下次访问”和“永久禁用”；全局禁用可在阅读设置中恢复。关闭菜单使用非模态 Radix DropdownMenu，支持方向键、Home/End、Esc 和 Tab 离开；迁移记录见 [Radix 与 LCP 基线](radix-lcp-acceptance.md)。
- 原站样式依赖导致的“图形可能不完整”和“保留了文字说明”仅由提示条说明，不再重复展示悬浮详情；只有这类问题时，提示文字使用普通文字，不进入键盘焦点。底层保留各自的问题记录，原文入口仍在文章元信息中。
- 新提取时，章节永久链接的装饰图标不计入图表问题；有图像语义或替代文字的绘图、图例与实际图表仍保留相应缺失说明。
- 已存 Browser Use 正文的标题锚点图片按同页链接和默认图标标识移除；完整作者名单改为紧凑署名，不因头部仅有一位作者而删掉其他作者。小图例保持行内显示，普通段落内插图继续居中并支持大图查看。
- Ghuntley OpenWebUI 文章中插入首句的书签标题作为链接拼回连续段落，卡片仍作为独立预览保留；旧译文补齐对应的连接语义。Z80 与 stdlib 两篇开头从 Ghost 提示框拆出的纯装饰 emoji 不作为正文首段，提示文字和正文中的 emoji 保留。
- 删除旧的每篇长期隐藏状态及其读写，清理浏览器已有的相应键。永久禁用偏好保留；文章、私人笔记及服务端数据不变。
- 文末提供来源、原文入口、点赞、主题与最多三篇公开相关文章；Geoffrey Huntley 文章省略文末重复的来源、原文入口与点赞一行，页首信息、文末主题、继续阅读和私人阅读区保留。来源例外由 `site/site.ts` 的 `ARTICLE_FOOTER.hideActionsForSources` 按来源 ID 配置。摘要去重覆盖正文开头的多段内容及引用；原文没有摘要时保持为空。正文能证明摘要为截断开头摘录时，展示到最后一个完整句子；没有完整句子则保留摘录和截断提示，不按缺少标点裁剪独立摘要。阅读时长按当前展示语言估算，无全文时不显示。
- 深色正文图片轻度调暗，悬停与查看器保留原色。查看器使用 `medium-zoom`，图片从正文原位以约300ms展开，关闭时缩回当前图片对应的位置；按正文元素区分相同URL的图片，切图后不收回到最初图片。缩放、平移后从当前画面连续收回，临时动画图片与查看器图片同步交接，收回后不重新显示大图；关闭动画结束后才移除图片、解锁页面滚动并归还焦点。当前正文图片已移除或不在视口时原地淡出，不跳转正文位置；开发与生产环境的普通页面均保留图片及背景的300ms过渡，包括启用“减少动态效果”时，无需预览参数；其他阅读动效同样保留原有时长。查看器以当前显示尺寸为起点，每步按1.25倍放大或缩小，范围从适应窗口到原图的400%，显示当前相对原图的百分比；保留适应窗口、原尺寸和鼠标拖动平移。缩放保持视野中心，超出可滚动范围时就近限位；切换或重新打开图片回到适应窗口。键盘可进入滚动区域，Esc关闭后归还焦点；调整桌面窗口大小保留查看器。
- 从搜索列表进入详情时保留关键词与命中字段/语种提示；只在当前公开展示的标题、导语、来源、主题及正文中重新查找。支持跨行内标签高亮，代码延迟着色后保持匹配，排除工具文案、行号与已折叠代码。点击“定位到首处匹配”才滚动，不覆盖后退/前进恢复；原文命中而当前显示中文译文时说明差异，并提供原文查找入口。旧命中不保证当前仍有匹配，不据此读取隐藏正文。
- 目录文字单次解码 HTML 实体，保留章节编号。具有当前正文目标证据的脚注在页面内往返；跨文档链接保留原地址。Browser Use 已确认的透明基准图保留来源深色底，正文、图片查看器和离线HTML一致。
- 视频手动播放，默认不预载。公开视频与海报通过当前文章、当前快照和已保存候选的哈希读取，逐次核对全文许可与可见性，并禁止缓存；字节范围每次最多1MiB，完整GET使用单一上游响应流（最多512MiB／60秒），避免跨版本拼接，取消阅读会中止上游。出站沿用地址、重定向、体积和类型检查；浏览器指纹桥接会缓冲响应，因此拒绝进入完整流预算。私人历史视频需管理员会话，离线ZIP仍提示访问原文。Google／OpenAI原生播放器旁的确定兼容兜底不作为正文段落展示；Ghost占位封面只可替换为原节点实际提供的背景图，来源未提供真实封面则移除失效占位图。
- 图片归档每篇最多256项，以容纳已核实的156图长篇演讲；单图8MiB、每篇64MiB继续生效。静态PNG／JPEG／WebP输入最多6400万像素，超过1600万像素时保留完整构图与透明度并缩放至输出预算内；更大输入和不支持的动画保持明确失败。失效的可选链接卡缩略图保留文字卡片，归档仍记录不完整。超过预算不会伪报保存成功。
