# 文章阅读工具调整

2026-10-31。按站主给出的掘金浮动工具与 Anthropic 专注模式参考，调整普通文章页。

## 约定

- 标题下保留元信息与摘要之间的一条横线，移除语言与正文类型工具栏。默认仍优先展示已有中文译文；打开原文始终位于元信息行。
- 阅读显示设置收进右下角的省略号按钮，面板向左上展开；下方依次为专注模式、主题切换、返回顶部。手机避开底栏与安全区。
- 专注模式仅作用于当前文章，隐藏侧栏、目录及手机导航，保持正文原有位置和宽度，按钮选中后变深色；再次点击退出并保留阅读位置。离开文章后恢复普通页面。
- 图表提示的文字在悬停、键盘聚焦或触屏点击时显示原有问题说明，可用 Esc 关闭。× 打开两个选项：本次关闭直到下次访问、永久禁用。前者只保存于本次文章组件，刷新或重新进入恢复；后者沿用浏览器的全局禁用偏好，可在阅读设置中恢复。
- 删除旧的每篇长期隐藏状态及其读写，清理浏览器已有的相应键。永久禁用偏好保留；文章、私人笔记及服务端数据不变。

修复保持原有容器、网格及侧栏占位，侧栏与目录以`visibility: hidden`隐藏。内容仍不显示且不能获得键盘焦点，正文保持原有位置和宽度；手机导航与阅读位置恢复继续沿用现有行为。

Chrome156检查有／无目录、窄／默认／宽三种阅读偏好及320、390、960、961、1024、1279、1280、1440、1920px窗口，共54组，开启和退出后的水平位移、正文宽度变化均为0。普通动态效果下又分别采样开启与退出的24帧，正文坐标及宽度保持一致。截图保存于本机`.data/focus-layout-fix/`。

## 阅读切换动效约定

按站主提供的美团返回顶部参考，浮动工具栏始终保留返回顶部槽位，按钮用180ms透明度渐变显隐；隐藏时不能点击或获得键盘焦点，其他按钮位置保持。专注模式开启、退出使用200ms交叉淡化，正文布局与阅读位置继续保持。

首页列表进入普通文章详情使用200ms交叉淡化；进入后焦点落到文章标题，浏览器后退恢复列表筛选、滚动位置与原文章链接焦点。减少动态效果时关闭动画；缺少View Transitions时直接完成状态与导航。沿用现有主题动效和React Router8.4能力，不新增依赖或改动其他页面的导航方式。

参考[Chrome的CyberAgent／Ameba阅读案例](https://developer.chrome.com/blog/view-transitions-case-studies#cyberagent)、[Tokopedia淡化案例](https://developer.chrome.com/blog/css-ui-ecommerce-vt#tokopedia)及[当前React Router8.4固定版本文档](https://reactrouter.com/8.4.0/api/components/Link#viewtransition)。这些案例支持采用轻量、保留上下文的过渡；本站的时长与范围为本次实现选择。

Chrome156复现旧实现中主题按钮随返回顶部显现从y=890移动到836；修正后始终为836。显现与消失各采22帧，记录到0–1之间的透明度，隐藏时禁用交互，主题坐标没有变化。专注开关与文章入口均观察到200ms淡化；桌面宽正文开启、退出时x=329、宽度=1200、scrollY=1500保持。连续6次专注开关后状态正确，无页面脚本错误。

320×568、390×667、1024×768、1920×958窗口与普通／减少动态效果两种偏好共8组：专注开启和退出各采20帧，正文无水平位移或宽度变化，无横向溢出；减少动态效果下没有文章视图动画。使用实际返回顶部按钮返回到0，手机底栏与固定槽位正确。证据位于本机`.data/reading-motion/`。

Node24.22.1类型检查与生产构建通过；隔离库`reader_reading_motion_test`仓库回归605/605、网页回归97/97通过，0失败／跳过。新增标题与返回链接焦点断言曾在改动前失败，修正后普通动画、无API降级、减少动态效果、快速开关及既有位置保持专项8/8通过。独立只读审查无问题；本机web已更新，smoke全部通过。
